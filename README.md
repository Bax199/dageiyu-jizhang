# 大肥鱼记账（新版）

安卓记账 App `com.bax.ledger2` 的安装包发行与版本更新仓库。

## 下载最新版

到本仓库的 **Releases** 页面下载最新 `.apk`，在安卓手机上打开即可覆盖安装（数据保留）。

- 适用：安卓 5.0 以上（华为 / 小米 / vivo / OPPO / 三星等，不依赖谷歌服务）
- iOS 与华为纯血鸿蒙（HarmonyOS NEXT）无法安装安卓 APK

## App 内检查更新

App 通过本仓库根目录的 `version.json` 检查新版本：有新版时打开 App 会弹窗提醒，点「立即更新」即跳转到对应 Release 下载安装包。

## 当前版本

- v0.1.8（versionCode 18）：家庭记账联网同步引擎、App 内检查更新、每日提醒、桌面式整屏滑动
